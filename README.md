Introducción
Este proyecto corresponde a la actividad individual de la guía SW-AyLP-APE-04, cuyo objetivo es aplicar programación orientada a objetos en C++ y Java mediante el uso de clases, objetos y métodos.
El sistema desarrollado permite registrar estudiantes de la asignatura Algoritmos y Lógica de Programación, calcular sus promedios y determinar si aprueban o reprueban.

Objetivos
Implementar clases con atributos privados y métodos públicos para garantizar la encapsulación.

Reutilizar código mediante objetos y métodos que disminuyan errores.

Validar notas y calcular automáticamente el promedio para determinar el estado del estudiante.
