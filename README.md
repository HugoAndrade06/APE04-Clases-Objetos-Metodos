Este proyecto corresponde a la práctica de programación orientada a objetos, implementada en **C++ y Java**.  
El sistema desarrollado permite gestionar estudiantes con sus datos personales y calificaciones, aplicando validaciones y cálculos automáticos.

## Descripción del proyecto
El programa solicita la información básica de cada estudiante (cédula, nombre, apellido y tres notas).  
Las notas ingresadas son validadas para que estén dentro del rango de 0 a 10.  
Posteriormente, se calcula el **promedio** y se determina el **estado académico**:  
- **Aprobado** si el promedio es mayor o igual a 7.  
- **Reprobado** si el promedio es menor a 7.  

Finalmente, se muestra un listado con la información completa de cada estudiante y se generan estadísticas globales de aprobados y reprobados.

## Objetivos
- Implementar la clase `Estudiante` con atributos y métodos básicos.  
- Aplicar validaciones en la entrada de datos.  
- Automatizar el cálculo de promedios y estados académicos.  
- Mostrar resultados individuales y estadísticas finales.  
- Evidenciar el proceso mediante commits organizados y capturas de ejecución.

## Estructura del proyecto
- `Cpp/` → Código en C++ con registro dinámico de estudiantes.  
- `Java/` → Código en Java con registro dinámico y estadísticas finales.  
- `capturas/` → Evidencias de ejecución y commits en GitHub Desktop.  
- `README.md` → Explicación general del proyecto y objetivos alcanzados.  

## Resultados obtenidos
- Se implementó un sistema funcional en C++ y Java que permite registrar estudiantes, validar notas y calcular promedios.  
- Se generó un listado con la información completa de cada estudiante.  
- Se obtuvieron estadísticas claras de estudiantes aprobados y reprobados.  
- Se reforzó el uso de **clases, objetos y métodos** en dos lenguajes distintos, cumpliendo con la guía práctica.
